Building a website blocker that respects your calendar

Schedules, the declarativeNetRequest API, and why “just one site” is never one site.

CONTENTS

  2. Rules, not scripts

I tried four blockers before writing my own. Each one either blocked everything all the time or let me disable it with a single click at 11pm. What I wanted was simpler: block a short list of sites during work hours on weekdays, and make turning it off slightly annoying.

This post walks through how the extension works, the one API that made it small, and the parts I would do differently if I started again.

Why build another one

Most blockers inject a content script into every page and check the URL. That works, but the page starts loading before the script runs, so you get a flash of the site you were trying to avoid. It also means asking for permission to read every page you visit.

The best blocker is the one that never lets the request leave the browser.

Rules, not scripts

Chrome's declarativeNetRequest API lets an extension hand the browser a list of rules up front. The browser applies them before any network request goes out, and the extension never sees your browsing.

chrome.declarativeNetRequest.updateDynamicRules({
  addRules: sites.map((host, i) => ({
    id: i + 1,
    action: { type: "redirect", redirect: { extensionPath: "/blocked.html" } },
    condition: { urlFilter: `||${host}`, resourceTypes: ["main_frame"] }
  })),
  removeRuleIds: existingIds
});
NOTE||host matches the domain and every subdomain, which is how one entry covers m.example.com too.

That is the whole blocking engine. Everything else in the extension is a settings page and a timer.

Scheduling

The schedule is a list of weekday and time ranges stored in chrome.storage.sync. An alarm fires at each boundary and swaps the rules in or out. Because alarms survive browser restarts, the block holds even if you quit Chrome to get around it.

What I'd change

I would add a “cool-down” instead of an off switch: request a break, wait five minutes, then get fifteen minutes of access. Friction works better than prohibition.
